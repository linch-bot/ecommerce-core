# Art Marketplace for Students — E-commerce Core

Реалізація високопродуктивного та масштабованого ядра бекенда (Core) для студентського маркетплейсу предметів мистецтва. В рамках проекту розроблено та оптимізовано ключові архітектурні патерни, асинхронні механізми та структури даних.

* **Группа:** 55
* **Мова програмування:** JavaScript (Node.js)

## 🚀 Реалізований функціонал (Архітектура та патерни)

У репозиторії представлено покрокову реалізацію наступних компонентів бізнес-логіки:

1. **Генератори Ітератори (`generator.js`, `iterator.js`)** — механізми для послідовної генерації та обходу колекцій об'єктів мистецтва без надмірного виділення пам'яті.
2. **Розумне Кешування (`memoization.js`)** — функція мемоізації для оптимізації "важких" обчислень (наприклад, динамічного розрахунку цін на картини). Підтримує конфігуровані стратегії витіснення даних із кешу:
   * **LRU** (Least Recently Used)
   * **LFU** (Least Frequently Used)
   * **Time-Based Expiry** (очистка за часом/TTL)
   * **Custom Policy** ( кастомні алгоритми очищення)
3. **Двоспрямована черга з пріоритетами (`priority-queue.js`)** — система управління замовленнями, що дозволяє гнучко витягувати елементи як за пріоритетом (VIP-замовлення/звичайні скетчі), так і за порядком додавання (FIFO/LIFO-логіка).
4. **Асинхронне оброблення масивів (`async-array.js`)** — асинхронна версія функції `map` у двох варіаціях: на базі коллбеків (Callbacks) та на базі Промісів (Promises) з повною підтримкою переривання операцій через `AbortController`.
5. **Інкрементальна обробка потоків даних (`data-stream.js`)** — ефективне оброблення великих масивів даних (історії продажів, логів) через асинхронні ітератори (`Async Iterators / Streams`) без навантаження оперативної пам'яті.
6. **Реактивна взаємодія (`event-emitter.js`)** — кастомний клас `EventEmitter` для слабкої зв'язаності модулів (мікросервісів повідомлень, аналітики та розсилок) з підтримкою динамічної підписки (`subscribe/unsubscribe`).
7. **Аутентифікаціоний Проксі (`auth-proxy.js`)** — захисний шар для API-запитів, що автоматизує підстановку облікових даних (API Key, JWT, OAuth), логування, Rate Limiting (захист від спаму) і автоматичне оновлення струменів, що закінчуються.
8. **Конфігурований декоратор логування (`logging-decorator.js`)** — універсальна обгортка для синхронних та асинхронних функцій. Підтримує рівні логів (INFO, DEBUG, ERROR), вимірювання часу виконання (профілювання), кастомні форматувальники та структурований висновок у форматі JSON.
